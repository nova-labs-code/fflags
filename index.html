Roblox Fast Flags Setup

Manual ClientAppSettings.json installation

1 Close Roblox

Completely close Roblox before changing the files.

2 Open the Roblox Versions folder

Press Win + R and paste:

Path
%localappdata%\Roblox\Versions

Press Enter.

3 Find the Roblox version

Open the version-... folder containing:

File
RobloxPlayerBeta.exe

4 Create ClientSettings

Inside that version folder, create a folder named:

Folder
ClientSettings

5 Open ClientSettings

Open the newly created ClientSettings folder.

6 Create ClientAppSettings.json

Create a new text document and rename it:

File
ClientAppSettings.json

Make sure Windows isn't hiding the .txt extension.

7 Open the JSON file

Open ClientAppSettings.json in Notepad.

8 Add the Fast Flags

Paste your Fast Flag configuration into the file and save it.

ClientAppSettings.json
{
  "FFlagDebugSkyGray": "true",

  "FFlagDebugForceNoTextures": "true",

  "FIntRenderShadowIntensity": "0",
  "FFlagRenderEnableGlobalShadows": "false",
  "FFlagRenderShadowsDisableAll": "true",

  "FIntFRMMinGrassDistance": "0",
  "FIntFRMMaxGrassDistance": "0",
  "FIntRenderGrassDetailStrands": "0",

  "FFlagFastGPULightCulling3": "true",

  "DFIntTaskSchedulerTargetFps": "1000",
  "FFlagTaskSchedulerLimitTargetFpsToConsoleFps": "false",

  "FIntRenderPreloadTextureLowerLimit": "1",
  "FFlagRenderGpuTextureCompressor": "true",

  "FIntGraphicsFRMQualityLevel1": "1"
}

9 Launch Roblox

Start Roblox normally. The configuration is loaded when the client starts.

10 Complete file location

The complete location is:

Path
%localappdata%\Roblox\Versions\version-XXXXXXXX\ClientSettings\ClientAppSettings.json
