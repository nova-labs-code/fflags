Roblox FPS Optimization

Manual ClientAppSettings.json setup

What this does: This configuration is intended to improve FPS by reducing the amount of rendering work Roblox has to perform. It removes or reduces things such as textures, shadows, grass, and other graphical effects. Results depend on your PC, Roblox version, and which flags are currently supported by Roblox.

1 Completely close Roblox

Before changing anything, completely close Roblox. Make sure the Roblox client is no longer running.

If Roblox is still running, close it before continuing.

2 Open the Roblox Versions folder

Press Win + R on your keyboard. This opens the Windows Run dialog.

Paste this location into the Run box:

Windows Run 
%localappdata%\Roblox\Versions

Press Enter.

3 Find the latest Roblox version

You will see multiple folders with names similar to:

Example 
version-xxxxxxxxxxxxxxxx

Roblox can have several versions installed at the same time. You want the latest version folder.

In File Explorer, click the Date modified column to sort the folders. Put the newest folder at the top.

Open the newest version-... folder.

Inside it, look for:

Roblox executable 
RobloxPlayerBeta.exe

If the folder does not contain RobloxPlayerBeta.exe, check the next newest version folder.

4 Create the ClientSettings folder

Inside the current Roblox version folder, right-click an empty area and select:

New → Folder

Name the folder:

Folder name 
ClientSettings

5 Open ClientSettings

Double-click the newly created ClientSettings folder.

You should now be inside the folder where the configuration file will be stored.

6 Create ClientAppSettings.json

Right-click inside the ClientSettings folder and select:

New → Text Document

Rename the new file to:

File name 
ClientAppSettings.json

Make sure the file does not end in .json.txt.

If Windows hides file extensions, enable:

View → Show → File name extensions

7 Open the JSON file

Right-click ClientAppSettings.json and select Open with → Notepad.

The file should be empty if you just created it.

8 Paste the FPS optimization configuration

Copy the configuration below and paste it into ClientAppSettings.json.

ClientAppSettings.json 
{
  "FFlagDebugSkyGray": "true",

  "FFlagDebugForceNoTextures": "true",

  "FIntRenderShadowIntensity": "0",
  "FFlagRenderEnableGlobalShadows": "false",
  "FFlagRenderShadowsDisableAll": "true",

  "FIntFRMMinGrassDistance": "0",
  "FIntFRMMaxGrassDistance": "0",
  "FIntRenderGrassDetailStrands": "0",

  "FFlagFastGPULightCulling3": "true",

  "DFIntTaskSchedulerTargetFps": "1000",
  "FFlagTaskSchedulerLimitTargetFpsToConsoleFps": "false",

  "FIntRenderPreloadTextureLowerLimit": "1",
  "FFlagRenderGpuTextureCompressor": "true",

  "FIntGraphicsFRMQualityLevel1": "1"
}

Press Ctrl + S to save the file.

9 Start Roblox

Close Notepad and launch Roblox normally.

The configuration is read when the Roblox client starts.

10 Your final file location

The final path will look similar to:

Final path 
%localappdata%\Roblox\Versions\version-XXXXXXXX\ClientSettings\ClientAppSettings.json

FPS Optimization

Why this can help: the configuration attempts to reduce rendering workload by disabling shadows, reducing grass rendering, removing textures, lowering certain graphics settings, and enabling GPU-related optimizations.

The DFIntTaskSchedulerTargetFps setting requests a 1000 FPS target, but this does not mean Roblox will actually render at 1000 FPS. Your monitor, GPU, CPU, game workload, and Roblox's current client restrictions still determine the actual FPS.

Important:

Roblox updates can create a new version folder. If that happens, the ClientSettings folder may need to be recreated in the newest version directory.

Also, Roblox currently restricts which Fast Flags can be changed through local configuration files. A flag being present in the JSON does not guarantee that the current Roblox client will honor it.
